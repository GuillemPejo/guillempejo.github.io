# guillempejo.github.io

Personal site of Guillem Pejó (indie Android & iOS developer), served by GitHub Pages.

- `index.html` + `css/site.css` + `js/site.js`: home page, English and Spanish in the same HTML (`data-l`), `?lang=es|en`.
- `img/apps/`: 192 px icons of the published apps (also used by the GitHub profile README).
- `apps-privacy/`: shared privacy policy of all the apps (linked from the stores; keep the URL).
- `terminos-ferrata/`: Ferrata terms of use.
- `app-ads.txt`: AdMob seller verification. **Do not remove or move**: Play and the App Store point to this domain.
